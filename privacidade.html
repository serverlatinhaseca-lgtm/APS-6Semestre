Privacidade no VerdeID

1. Reconhecimento facial é simulação. A “verificação de rosto” deste site é uma encenação visual (animação + prévia opcional de câmera). Nenhuma imagem é gravada, enviada a servidor ou usada para identificação real.

2. Dados de conta. Login/cadastro demo são guardados apenas no seu navegador (localStorage/sessionStorage). Não há backend nesta versão [DEMO]. Para limpar, use “Sair” ou limpe os dados do site.

3. Níveis de acesso. A classificação Cidadão/Pesquisador/Gestor é [PROVISÓRIA] para fins acadêmicos, até a proposta oficial definir perfis e permissões.

4. Artigos. Todo o acervo é conteúdo ilustrativo [DEMO] e não constitui orientação normativa ambiental.
